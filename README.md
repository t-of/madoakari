# まどあかり — 夜の窓をぜんぶ灯す

夜の建物の窓をタップして明かりをつける。押した窓と上下左右のとなりが一緒に切り替わるので、どこを押すかを考えて、なるべく少ない数で全部の窓を灯す。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/madoakari/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 窓をタップすると、その窓と上下左右のとなりの明かりが切り替わる（ついていれば消え、消えていればつく）。
2. 全部の窓が灯ったらクリア。
3. 押した数が少ないほどよい。いちばん少ない数も出る。同じ窓をもう 1 回押すと元に戻る。

- 大きさは 3×3〜7×7 から選ぶか、「じぶんで」で縦・横をそれぞれ 2〜12 にできる。
- 始まりの形は「まっくら」「たてじま」「いちまつ」「おまかせ」（毎回ちがう盤）。その大きさで解けない形は選べない。
- 「はじめから」で同じ盤をやり直す。おまかせのときは「べつの盤」で新しい盤にする。
- 大きさと形ごとに、クリアしたときのいちばん少ない押した数を記録する（おまかせは記録しない）。
- 音はタイトルの「音 オン / オフ」で切り替えられる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 押す・解けるか・いちばん少ない数・保存のテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `logic.js` | 盤・押す・始まりの形・解けるかの判定といちばん少ない数（掃き出し法）・保存する値の確かめ（DOM に触らない） |
| `main.js` | 画面の切り替え・操作・描画・音 |
| `test.mjs` | `logic.js` のテスト |

- 解けるか: 「どの窓を押すか」を未知数にした 2 を法とする連立方程式を掃き出し法で解く。解がなければその形はその大きさで解けない。
- いちばん少ない数: 解を 1 つ出し、押しても盤が変わらない押し方（核）の組み合わせを全部試して、押す窓が最も少ないものを取る。2〜12 の盤では核の次元は 8 以下（256 通り以下）。
- 保存は端末内の `localStorage`。`madoakari.settings`（`{ v: 1, rows, cols, pattern, sound }`）と `madoakari.best`（`{ v: 1, records: { '5x5-blank': 17 } }`）。
